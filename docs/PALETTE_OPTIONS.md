# Accentpaletter för jämförelse

Tre alternativ för en neutral, ljus matapp. Samtliga värden är hex-koder. Kontrasten är beräknad enligt WCAG 2.x för vit text (`#FFFFFF`) på primärfärgen.

| Token | Terrakotta | Blå | Frisk grön · standard |
| --- | --- | --- | --- |
| Primär | `#95613E` | `#356D96` | `#16805C` |
| Hover | `#784B2E` | `#285574` | `#116446` |
| Soft | `#F7EEE7` | `#E7F1F7` | `#E7F0E9` |
| Ink | `#292B30` | `#292B30` | `#292B30` |
| Muted | `#5C6068` | `#5C6068` | `#5C6068` |
| Line | `#E1E2E6` | `#E1E2E6` | `#E1E2E6` |
| Vit text på primär | **5.18:1** | **5.56:1** | **4.91:1** |

Alla tre primärfärger klarar WCAG AA för normalstor vit text, med gränsen 4.5:1.

## Kort motivering

- **Terrakotta:** varm och aptitlig accent som knyter an till tomat, kryddor och matlagning utan att ta över den ljusa grundytan.
- **Blå:** tydlig, sval accent med god läsbarhet som ger appen ett lugnare och mer neutralt uttryck.
- **Frisk grön (standard):** associerar till råvaror och vardagsmat; den tydliga primärtonen behåller tydlig kontrast mot vit knapptext.

`Soft` är avsedd för diskreta ytor och markeringar, `Ink` för huvudtext, `Muted` för sekundär text och `Line` för tunna avdelare och kanter.
