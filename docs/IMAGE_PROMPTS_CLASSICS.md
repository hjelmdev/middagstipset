# Bildprompter för klassiska vardagsrätter

Bilderna genererades med den inbyggda ImageGen-funktionen, en bild per rätt. Alla använder fotorealistisk naturlig matfotografi, landskapsformat 3:2, mjukt dagsljus, blekt ekbord och enkel offwhite keramik. Receptens ingredienslistor styr vad som syns i maten; inga extra tillbehör eller garneringar ska läggas till.
