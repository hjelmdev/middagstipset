# Bildprompter: vegetariska recept

Bilderna skapades med Codex inbyggda imagegen-verktyg, en generering per recept. Samtliga är 3:2 liggande fotorealistiska vardagsmatsbilder för appens receptkort och receptvy. Jag granskade varje genererad bild visuellt mot receptets ingredienser innan den kopierades till `assets/recipe-image-sources/`.
